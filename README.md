# android_hardware_samsung_slsi-cm_exynos5422

Módulos HAL oficiais adaptados para o processador Exynos 5422 Octa-Core presente no Samsung Galaxy S5 (SM-G900H).

## 🛠️ Tecnologias

- **C**
- **C++**
- **Android HAL**
- **Exynos 5422**

## 📂 Estrutura do Projeto

- `gralloc/`: Suporte a buffers gráficos.
- `libcamera/`: Integração do sensor de câmera do S5.
